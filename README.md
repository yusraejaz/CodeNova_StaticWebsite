# Yusra Ejaz — Developer Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Features

- Responsive desktop and mobile layout
- About, Skills, Projects and Education sections
- Project preview cards
- Contact and social profile links
- Mobile navigation menu
- Dedicated image assets folder
- GitHub Pages deployment support

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Project Structure

```text
CodeNova_StaticWebsite/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── images/
        ├── profile.jpg
        ├── project-1.jpg
        ├── project-2.jpg
        └── project-3.jpg
```

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. For development, use Visual Studio Code and a local preview extension.

## Add Images

Place your own image files in `assets/images/`.

Keep these filenames consistent with the paths used in `index.html`.

## Customize

Update your email address, GitHub and LinkedIn profile links, project descriptions, and certificate links before publishing.

## Deployment

The deployment walkthrough, GitHub Pages configuration, HTTPS verification, and live URL will be added after the deployment has been completed and tested.

## Security

This is a static website and does not require API keys, passwords or private credentials.
